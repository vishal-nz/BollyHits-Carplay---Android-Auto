BollyHits Radio Player

Automatic channel switching removed. Select one of four stations manually or use the previous/next controls. The selected stream stays active until changed. Metadata updates every 15 seconds. Media Session metadata includes song title, artist, artwork, and channel/listener information in the album field where supported.

IMPORTANT: Confirm the stream URLs in index.html against the actual AzuraCast public listen URLs. Browser CORS and vehicle/browser capabilities may affect metadata display.
